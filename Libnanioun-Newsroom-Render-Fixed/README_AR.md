# غرفة أخبار لبنانيون — الإصدار الأول

لوحة نشر عربية (موبايل + كمبيوتر) مع شعار لبنانيون المرفق:

- حفظ وتعديل مسودات الأخبار مع عنوان ومتن ومصدر ورابط وصورة.
- عرض ومراجعة الصورة، وخيار «عاجل».
- نشر مباشر إلى **صفحة Facebook** باستخدام واجهة Meta الرسمية بعد موافقة المحرّر.
- تجهيز نص وصورة لقناة WhatsApp للنسخ والرفع اليدوي. **لا ينشر تلقائياً على القناة.**
- متابعة الأخبار المنشورة وتحديد إن كان الخبر نُشر يدوياً في القناة.
- دخول بكلمة سرّ، ومنع تكرار الإرسال عند الضغط مرّتين، وتسجيل حالات النشر غير المؤكّدة.

## 1. التجربة على جهازك (Python 3.11+)

افتح مجلد البرنامج، ثم نفّذ:

```bash
python -m pip install -r requirements.txt
```

عيّن المتغيّرات السرية في بيئة جهازك (مثال لنظام Linux/macOS):

```bash
export ADMIN_USERNAME=admin
export ADMIN_PASSWORD='اكتب-كلمة-سر-قوية-خاصة-بك'
export SECRET_KEY='اكتب-قيمة-عشوائية-طويلة-لجلسات-الدخول'
python app.py
```

افتح `http://127.0.0.1:5000` ثم سجّل الدخول.

في Windows PowerShell:

```powershell
$env:ADMIN_USERNAME='admin'
$env:ADMIN_PASSWORD='اكتب-كلمة-سر-قوية-خاصة-بك'
$env:SECRET_KEY='اكتب-قيمة-عشوائية-طويلة-لجلسات-الدخول'
python app.py
```

البرنامج يعمل محلياً لتجربة المسودات حتى بدون ربط Facebook. النشر الفعلي يتطلّب مفاتيح وصلاحيات Meta صحيحة.

## 2. رفعه على GitHub ثم Render

1. أنشئ مستودع GitHub **خاص Private** جديد باسم `libnanioun-newsroom` وارفع **محتويات المجلد** بما فيها `app.py` و`templates` و`static` و`requirements.txt`.
2. لا ترفع ملفات `.env` التي تحتوي أسراراً؛ المشروع يتضمّن `.gitignore` لهذا السبب.
3. ادخل [Render](https://dashboard.render.com)، ثم `New` → `Web Service`، اختر المستودع.
4. اختر Python، وأدخل:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn --bind 0.0.0.0:$PORT app:app`
5. من `Environment` أضف:
   - `ADMIN_USERNAME`: اسم الدخول الذي تختاره، مثل `admin`.
   - `ADMIN_PASSWORD`: كلمة مرور قويّة لا ترسلها لأحد.
   - `SECRET_KEY`: سلسلة عشوائية طويلة (32 بايت أو أكثر)، يمكن توليدها محلياً عبر `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
   - `FACEBOOK_PAGE_ID`: معرّف صفحة لبنانيون.
   - `FACEBOOK_PAGE_ACCESS_TOKEN`: رمز وصول الصفحة من Meta **ولا تضعه في المحادثة أو GitHub**.
   - `GRAPH_API_VERSION`: `v26.0` (يمكن تغييره إذا طلبت Meta نسخة مختلفة).
   - `WHATSAPP_CHANNEL_URL`: الرابط الحقيقي لقناة لبنانيون، اختياري.
6. افتح الرابط الذي يعطيك Render، وجرّب حفظ خبر كمسودة قبل ربط فيسبوك.

### مهم جداً: تخزين الأخبار والصور

خدمة Render العادية قد تستخدم ملفات **مؤقتة** تُحذف عند إعادة تشغيل الخدمة أو تحديثها. هذا يشمل قاعدة SQLite والصور، ولذلك **لا تعتمد عليها في العمل الفعلي دون تخزين دائم**. للاستخدام الحقيقي، اربط `Persistent Disk` على Render (إن كانت خطتك تدعمه) بالمسار `/var/data` واضبط `DATA_DIR=/var/data`، وخذ نسخاً احتياطية دورية. لا تستخدم عدة نسخ تشغيل للتطبيق مع SQLite على قرص مشترك. يمكن تطوير النسخة التالية إلى PostgreSQL وتخزين صور دائم.

## 3. ربط صفحة Facebook رسمياً

ستحتاج إلى حساب مطوّر [Meta for Developers](https://developers.facebook.com/)، وتطبيق Meta، وصلاحيات المناسبة للنشر على صفحة أنت مخوّل إدارتها. الصلاحيات المعتادة: `pages_manage_posts`, `pages_read_engagement`, `pages_show_list`. قد يتطلّب الاستخدام خارج وضع التطوير `App Review` أو `Business Verification` حسب نوع الصلاحية والتطبيق.

بعد الحصول على **Page Access Token** ومعرّف الصفحة، خزّنهما في Render Environment؛ لا تضفهما إلى ملفات مصدر المشروع. بعض رموز الوصول تنتهي أو تُلغى عند تغيير الصلاحيات؛ عند فشل النشر راجع صلاحية الرمز.

البرنامج يستخدم:

- نص فقط: `POST /{page-id}/feed`
- مع صورة: `POST /{page-id}/photos`

زر «اعتماد ونشر» يتطلّب اختيار مربع تأكيد التدقيق ويعرض تأكيداً إضافياً. بعد الضغط يستدعي واجهة Meta؛ **لم يتم نشر أي شيء فعلياً قبل إتمام الربط وإجراء عملية نشر ناجحة**.

## 4. نشر قناة WhatsApp

افتح الخبر في اللوحة واضغط «نسخ نص الخبر»، ثم «تنزيل الصورة» إن وُجدت، وافتح القناة من تطبيق WhatsApp كمسؤول، والصق النص وأرفق الصورة وانشر. بعدها اضغط «تم النشر على قناة واتساب» في اللوحة.

لا تتعامل مع واجهة WhatsApp Business API الخاصة بالمحادثات كأنها API للنشر في Channels؛ التطبيق **لا يستخدم أي وسيلة غير رسمية** للنشر في القنوات.

## تنبيهات

- يجب التحقّق من الأخبار والمصادر قبل النشر، خصوصاً الأخبار الحساسة والاتهامات.
- ميزة هذه النسخة: صورة واحدة لكل منشور، ولا تدعم الفيديو أو النشر المجدول بعد.
- نسخة أولى للاستخدام الفردي؛ لاستعمال فريق كبير أضف إدارة مستخدمين وأدوار وسجلات تدقيق ونسخاً احتياطية.
- إذا انقطع الاتصال أثناء النشر، الحالة تتحوّل إلى «تحقّق من فيسبوك» ولا تتم إعادة المحاولة تلقائياً حتى لا يتكرر المنشور.
